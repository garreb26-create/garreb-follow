# جرّب · المتابعة

تطبيق جوال (PWA) ساكن لمتابعة المبيعات والمالية والعملاء وإرسال رسائل واتساب بضغطة.
يُستضاف على GitHub Pages مجانًا ويقرأ من قاعدة جرّب مباشرة بعد تسجيل الدخول.

- لا خادم ولا بيانات في هذا المستودع. كل شيء يُجلب بعد تسجيل الدخول وتحكمه سياسات القاعدة (RLS).
- المفتاح في `app.js` من نوع publishable: مصمَّم ليكون علنيًا ولا يمنح وحده أي وصول.
- الدخول مقصور على الحسابات في جدول `allowed_login_emails` داخل القاعدة.
- لا إرسال آلي لواتساب: التطبيق يفتح المحادثة بنص جاهز وتضغط «إرسال» بنفسك.

## التثبيت على الجوال
افتح الرابط في Chrome (أندرويد) أو Safari (آيفون) ثم «إضافة إلى الشاشة الرئيسية».
